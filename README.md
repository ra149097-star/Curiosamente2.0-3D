# NeuroDetetive 3D PWA
Jogo responsivo de investigação forense em 7 fases com quiz de neuroanatomia, quadro de pistas, revelação progressiva do suspeito, som sintetizado, alto contraste, fonte ampliada e painel de apoio VL Libras.

## GitHub Pages
Envie todo o conteúdo desta pasta para a raiz do repositório. Em Settings > Pages, selecione Deploy from a branch, branch main e /root.

## Imagens
As imagens anexadas já estão incorporadas em `assets/img`. Para acrescentar `cerebelo.png`, `corpo-caloso.png`, `hipotalamo.png`, `occipital.png` e `terceiro-ventriculo.png`, basta colocar esses arquivos na mesma pasta e atualizar as fases em `app.js`.

## Áudio
A versão completa inclui os efeitos sonoros enviados: `acerto.mp3`, `erro.mp3`, `poder.mp3` e `vitoria.mp3`. O botão Som ativa/desativa todos os efeitos.
